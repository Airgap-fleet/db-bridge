# AFaaS — Local-First Multi-Agent AI Agency

> **Agent Fleet as a Service** — Deployable, private, persistent agent teams on client infrastructure.

---

## Mission
Build a £387K Year 1 business delivering three revenue streams:
1. **Fleet Deployment** — Custom agent teams for client workflows
2. **MCP Server Products** — Reusable Model Context Protocol servers
3. **Local LLM Optimization** — Quantize, serve, tune models on client hardware

---

## Core Differentiators
- **Fully local** — Data never leaves client premises
- **Persistent memory** — Shared Obsidian vault across agent fleet
- **Productized fleet** — 12-agent team as deployable unit, not consulting hours
- **MCP-native** — Standardized tool interface, works with Claude, Cursor, VS Code
- **Hermes + Ollama + DirectML + Obsidian** — Coherent stack few agencies possess
