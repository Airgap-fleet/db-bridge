## 📈 Standard Operating Procedures (SOPs)

### Daily Operations
1. **Morning**: Review dashboards (BI under Rupert), triage incidents (Sec → SRE under CTO)
2. **Midday**: Pipeline standup with Master review
3. **Afternoon**: Dev sync (CTO + Dev + QA under Rupert), content publishing (DOCS + Smarketing under PM)
4. **Evening**: Incident wrap-up (SRE), customer alerts (NO under OPM team lead)

### Weekly Rhythm
- **Monday**: Roadmap review (PM under CEO-Rupert), week planning with Master approval
- **Wednesday**: Feature demo (VP_Sales + DOCS under Sales VP)
- **Friday**: Sprint recap, metrics report (CFO → CEO-Rupert → Master for final review)

### Monthly Cadence
- First week: Financial close (CFO under CFO), product retrospective (PM under PM Lead)
- Second week: Security audit (Sec → CLO under Sec Lead), partner reviews (VP_Sales + AC)
- Third week: Community AMA (EDU), content marketing review (Smarketing + SE)
- Last week: OKR planning, hire if needed (under CEO-Rupert)

## 🎓 Training & Onboarding

### New Agent Protocol
1. **Context dump**: Full skill vault access + session_history queries
2. **Shadow period**: 1-week observation of existing roles under Rupert supervision
3. **Task assignments**: Progressive responsibility ramp-up
4. **Documentation review**: Domain-specific SOPs
5. **First autonomous task**: Under supervision

### Knowledge Transfer
- All agent skills saved as skill.md files in Hermes vault structure
- Context retrieval via session_search(query) before delegation
- Handoff notes stored in shared folder with wikilinks
